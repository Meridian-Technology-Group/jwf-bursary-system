With respect to last Friday’s meeting, I just wanted to clarify the statuses:

For an application form, you should have:

1. **Created** : the assessor has entered the contact details of the selected family and has sent them an invitation/link to apply.
2. **Not started**: the applicant has logged into the portal at least once but has not started the application
3. **In progress**: the applicant has started the application but has paused it and it is not yet complete
4. **Filled in**: the full application has been filled in with all the required documents attached and fields answered
5. **Received (new applications) :** the application has been submitted, and a submission summary PDF downloadable option has been offered to the applicant. (yes or no, the option goes away if the applicant presses no)
6. **Submitted (rolling-over applications) :** the application has been submitted, and a submission summary PDF downloadable option has been offered to the applicant. (yes or no, the option goes away if the applicant presses no)

For the assessment, you should have:

1. **Not started:** the assessor has not opened the assessment yet
2. **In progress:** the assessor has started the assessment but is still in the middle of reviewing the documents
3. **Paused:** the assessor has started the assessment but has had to pause it due to missing documents, information (maybe an option to enter a deadline date by which the applicant needs to email the missing documents or attach them to a link which is then populating the form retrospectively would useful.
4. **Complete:** the assessment is finished and a decision on payable fees/bursary award is keyed in.
