# Change Requests

Statements of work for changes that fall **outside** the Annual Licence Fee and
are quoted separately under **clause 9.5** of the
[Master Services Agreement](../master-services-agreement.md), typically new
major features, calculation-model changes, external integrations, or migration
work (MSA clause 9.3).

Each CR is a self-contained scope + quote. On the Customer's written approval it
becomes the signed statement of work required by clause 9.5(d) and is governed
by the MSA. No work begins until the quote is approved in writing.
